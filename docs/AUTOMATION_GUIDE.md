# Automated Support Card Scraping Guide

This document describes the automated system for detecting and scraping missing Global version support cards from Gametora.

## Overview

The automation system consists of:
1. **Support Registry**: Tracks which support cards have been scraped (`datasets/in_game/support_registry.json`)
2. **Detection Logic**: Compares existing data with Gametora to find missing supports
3. **Automation Script**: Orchestrates the entire process (`datasets/auto_scrape_missing_supports.py`)
4. **Safety Features**: Dry-run mode, validation, and manual confirmation steps
5. **Auto-Discovery**: Automatically finds all available Global version supports from Gametora's index page

## Usage

### Basic Usage

Check specific supports for missing data:

```bash
python datasets/auto_scrape_missing_supports.py \
    --support-list "30036-riko-kashimoto,30034-rice-shower,20029-seeking-the-pearl"
```

### Auto-Discovery Mode

Automatically discover all Global version supports from Gametora's supports index page:

```bash
python datasets/auto_scrape_missing_supports.py --discover-all --dry-run
```

### Dry Run Mode

See what would be scraped without actually doing it:

```bash
# With specific support list
python datasets/auto_scrape_missing_supports.py \
    --support-list "30036-riko-kashimoto,30034-rice-shower" \
    --dry-run

# With auto-discovery
python datasets/auto_scrape_missing_supports.py \
    --discover-all \
    --dry-run
```

### Force Rescan

Ignore the registry and check all specified supports (useful for initial setup):

```bash
python datasets/auto_scrape_missing_supports.py \
    --support-list "30036-riko-kashimoto,30034-rice-shower" \
    --force-rescan

# With auto-discovery
python datasets/auto_scrape_missing_supports.py \
    --discover-all \
    --force-rescan
```

### Debug Mode

Enable verbose logging:

```bash
python datasets/auto_scrape_missing_supports.py \
    --support-list "30036-riko-kashimoto,30034-rice-shower" \
    --debug

# With auto-discovery
python datasets/auto_scrape_missing_supports.py \
    --discover-all \
    --debug
```

## Workflow

When you run the automation script, it will:

1. **Load existing supports** from `datasets/in_game/events.json` and the support registry
2. **Discover supports** (if `--discover-all` is used) or use specified supports (if `--support-list` is used)
3. **Fetch data from Gametora** for the supports to check using JSON mode
4. **Compare** the data to find which supports are missing from your local data
5. **Generate appropriate support defaults** for the scraper based on missing supports
6. **Show you what's missing** and ask for confirmation before proceeding (unless `--force-rescan`)
7. **Run the event scraper** with the generated defaults
8. **Prompt you to manually merge** the scraped data into `events.json`
9. **Optionally run `build_catalog.py`** to update the event catalog
10. **Update the support registry** with the current timestamp

## Safety Features

- **Dry Run Mode**: Preview what would happen without making changes
- **Manual Confirmation**: Requires explicit approval before scraping and building (can be bypassed with `--force-rescan`)
- **Manual Data Merge**: You review and merge scraped data into `events.json` yourself (key safety feature)
- **Registry Tracking**: Prevents re-scraping the same supports unnecessarily
- **Error Handling**: Graceful failure with informative messages
- **Version Detection**: Automatically filters out Japanese version supports (Global-only scraping)

## Integration with Existing Workflow

This automation enhances (but doesn't replace) the existing manual workflow described in `README.dev.md`:

1. **Instead of manually guessing** which supports need scraping, the system detects them automatically
2. **Instead of manually specifying** `--support-defaults`, the system generates them based on missing data
3. **Instead of maintaining a manual list**, you can use `--discover-all` to automatically find all Global version supports
4. The core scraping logic remains unchanged - we just make it smarter about what to scrape
5. You still need to manually verify and merge the data (this is a safety feature)
6. You still need to run `build_catalog.py` (though the script can do this for you)

## Configuration

The system uses these key files:

- `datasets/in_game/support_registry.json` - Tracks scraped supports (auto-managed)
- `datasets/in_game/events.json` - Master event data (you maintain this)
- `datasets/in_game/event_catalog.json` - Runtime catalog (auto-generated by build_catalog.py)
- `datasets/auto_scrape_missing_supports.py` - Automation script

## Extending the System

To make this fully automatic (without the manual merge step), you would need to:

1. Implement automatic merging of scraped data into `events.json`
2. Add more sophisticated Global vs Japanese version detection
3. Implement scheduled execution (cron job or similar)

See the source code for TODO comments indicating where these enhancements could be added.

## Examples

### Check Specific Supports
```bash
# Check if specific supports need updating
python datasets/auto_scrape_missing_supports.py --support-list "30036-riko-kashimoto,30034-rice-shower"

# See what would be done without making changes
python datasets/auto_scrape_missing_supports.py --support-list "30036-riko-kashimoto,30034-rice-shower" --dry-run

# Force a rescan of specific supports
python datasets/auto_scrape_missing_supports.py --support-list "30036-riko-kashimoto,30034-rice-shower" --force-rescan
```

### Auto-Discover All Supports
```bash
# Discover all Global supports and see what needs updating
python datasets/auto_scrape_missing_supports.py --discover-all --dry-run

# Discover all Global supports and scrape missing ones
python datasets/auto_scrape_missing_supports.py --discover-all --force-rescan

# Combine discovery with specific list (union of both)
python datasets/auto_scrape_missing_supports.py --discover-all --support-list "30036-riko-kashimoto" --dry-run
```

### Workflow Example
```bash
# 1. Check what needs updating (recommended first step)
python datasets/auto_scrape_missing_supports.py --discover-all --dry-run

# 2. If the results look good, proceed with scraping
python datasets/auto_scrape_missing_supports.py --discover-all --force-rescan

# 3. Follow the prompts to:
#    - Review and merge scraped data into datasets/in_game/events.json
#    - Run build_catalog.py to update the runtime catalog
#    - The support registry will be updated automatically
```
